# 👁️ Visual Perception Challenge

An interactive web-based game designed to challenge visual perception, attention, memory, pattern recognition, and logical thinking.

## 🎯 Features

- 👀 Visual perception challenges
- 🧠 Memory and attention tasks
- 🧩 Pattern recognition
- 💡 Logical reasoning
- 🔄 Cognitive flexibility
- 📊 Progressive scoring

The next challenge appears only after the current one is answered correctly. One incorrect answer ends the current run.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages
